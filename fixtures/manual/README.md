# Manual Apps Script snapshots

Frozen copies of spreadsheet-bound script files used to port Lattice support into this repository.

- `functions.gs` — merged Apps Script from Google Apps Script editor (2026-05-12).
- `code.gs` — webpack-style bundle from the same project (menu spec reference only).

Do not edit these files when changing product behavior; update `functions/*.js` and `src/server/` instead.
